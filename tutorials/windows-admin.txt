SST — Administración Windows / Nwash

Todos estos comandos admiten ayuda con ausencia de argumentos o `help`, `-h`, `--help` según su builtin. Las mutaciones pueden requerir `sudo`.

EVENTLOG
  eventlog list
  eventlog publishers
  eventlog info LOG
  eventlog read [LOG] [--count N] [--query XPATH] [--xml]
  eventlog export LOG ARCHIVO [--query XPATH] [--overwrite]
  eventlog clear LOG [--backup ARCHIVO]

Defaults de read: LOG=System, count=20, texto, newest-first. Backend: wevtutil.exe.

SERVICE
  service list
  service list --running
  service list --stopped
  service status NOMBRE
  service start NOMBRE
  service stop NOMBRE
  service pause NOMBRE
  service resume NOMBRE
  service restart NOMBRE

restart hace stop, espera STOPPED (hasta ~10 s) y luego start. Backend: sc.exe.

REGISTRY — lectura y escritura
  registry get CLAVE
  registry get CLAVE --value NOMBRE
  registry get CLAVE --default
  registry get CLAVE --recursive
  registry set CLAVE NOMBRE DATO [--type TIPO]
  registry set-default CLAVE DATO [--type TIPO]
  registry delete CLAVE --value NOMBRE
  registry delete CLAVE --default
  registry delete CLAVE --key
  registry export CLAVE ARCHIVO [--overwrite]
  registry import ARCHIVO

TIPO documentado/aceptado por reg.exe a través de SST:
  REG_SZ
  REG_EXPAND_SZ
  REG_DWORD
  REG_QWORD
  REG_MULTI_SZ
  REG_BINARY

`set` y `set-default` fuerzan confirmación /f; delete también. Backend: reg.exe.

PROCESS
  process list
  process info PID
  process tree PID
  process kill PID
  process kill PID --tree
  process kill PID --force
  process kill PID --tree --force

list/info: tasklist.exe; kill: taskkill.exe; tree: árbol interno sysinfo.

ACL
  acl show RUTA
  acl grant RUTA USUARIO PERMISO
  acl deny RUTA USUARIO PERMISO
  acl revoke RUTA USUARIO
  acl inherit RUTA on
  acl inherit RUTA off
  acl reset RUTA

PERMISO pasa a icacls; ejemplos: F, M, RX, R, W. Backend: icacls.exe.

PNP
  pnp list
  pnp list --connected
  pnp list --disconnected
  pnp list --problem
  pnp info INSTANCE_ID
  pnp enable INSTANCE_ID
  pnp disable INSTANCE_ID
  pnp restart INSTANCE_ID
  pnp scan

Backend: pnputil.exe. Mutaciones/rescan pueden requerir elevación.

TASK
  task list
  task list --verbose
  task list --csv
  task show NOMBRE
  task show NOMBRE --xml
  task run NOMBRE
  task end NOMBRE
  task enable NOMBRE
  task disable NOMBRE
  task delete NOMBRE

Delete se ejecuta forzado (/F). Backend: schtasks.exe.

SESSION
  session list
  session users
  session logoff ID
  session message ID TEXTO...

Backend: query.exe, logoff.exe, msg.exe. Cerrar/mensajear sesiones ajenas puede requerir permisos.

SHARE
  share list
  share sessions
  share files
  share add NOMBRE RUTA
  share remove NOMBRE

Backend: net.exe. remove usa /delete /y.

FIREWALL
  firewall status
  firewall rules
  firewall rule NOMBRE
  firewall enable PROFILE
  firewall disable PROFILE

PROFILE admitido:
  domain
  private
  public
  all

Backend: netsh.exe advfirewall. Enable/disable cambia estado del perfil, no crea reglas nuevas.

POWER
  power shutdown
  power shutdown --force
  power restart
  power restart --force
  power logoff
  power logoff --force
  power hibernate

shutdown/restart/logoff usan timeout 0; --force añade /f. Backend: shutdown.exe.

SEGURIDAD
  No uses comandos mutadores solo porque están disponibles. ACL, Registro, PnP, tareas, shares, firewall, servicios y energía pueden afectar disponibilidad o acceso del equipo. Usa `sudo COMANDO...` cuando Windows exija privilegios y valida el resultado con el comando de lectura correspondiente.
