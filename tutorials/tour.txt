SST — Tour interactivo

Comando público:
  tour

El nombre interno `sst-tour-select` existe para integración pero el usuario debe usar `tour`.

Teclas:
  Up / Down               mover selección
  PgUp / PgDn             saltar 5 posiciones
  Home / End              primera/última
  Enter                    seleccionar/ejecutar ejemplo
  q / Q / Esc             salir

Ejemplos empaquetados detectados por SST:
  01-language-tour.sh                 lenguaje Nwash: funciones, arrays, case, aritmética
  02-windows-operator-report.sh       reporte de sistema/administración
  03-network-discovery.sh             scan, inventario, snapshots, diff
  04-jobs-and-coproc.sh               jobs, background, wait, coproc, descriptores
  05-pipelines-and-text.sh            grep, sed, cut, sort, tee, hashes
  06-security-triage.sh               persistencia, firmas, intel, eventos
  07-operator-console.sh              menú interactivo Nwash
  08-config-and-backgrounds.sh        fondos/carrusel/config
  09-advanced-bash.sh                 getopts, nameref, mapfile, printf -v
  10-full-showcase.sh                 recorrido amplio SST

Tour lee los scripts `.sh` de la carpeta examples/ y devuelve la ruta seleccionada para que la shell la ejecute.
