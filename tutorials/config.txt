SST — Configuración portable: config / sst-config / sst-path

En la próxima revisión de SST (todavía no publicada en el canal Blue), escribe config para abrir el formulario de sstrc. En blue.11 continúa disponible config edit. Cambia los valores, selecciona Guardar o descarta el borrador con Cancelar. Los alias y las variables de shell se recargan con config reload.

Backend nativo:
  sst-config

Ruta de configuración:
  sst-config
  sst-config path

Editar:
  sst-config edit

Fondos — listar:
  sst-config bg
  sst-config bg list

Desactivar:
  sst-config bg off
  sst-config bg none          alias

Fondo fijo:
  sst-config bg NOMBRE
  sst-config bg NUMERO

NOMBRE puede coincidir con nombre de archivo o stem. NUMERO corresponde al listado actual.

Carrusel:
  sst-config bg carrousel
  sst-config bg carousel      alias ortográfico
  sst-config bg carrousel MINUTOS

MINUTOS:
  entero 1..60
  default 3

Rotación manual:
  sst-config bg next

Formatos reconocidos por la carpeta bg según SST:
  PNG, JPG, JPEG, WebP, BMP, GIF, ICO, TIFF

Variables gestionadas:
  SST_BACKGROUND_MODE
  SST_BACKGROUND_IMAGE
  SST_BACKGROUND_CAROUSEL_MINUTES

Reload:
  config reload               recarga el entorno desde la interfaz pública. El backend directo sst-config reload no recarga la shell.

Rutas:
  sst-path PATH

`sst-path` traduce/resuelve rutas estilo /c/... contra el directorio de trabajo al modelo Windows.

`config` es la interfaz pública incorporada de SST; `sst-config` es el backend explícito. El intérprete reenvía las operaciones de apariencia al backend y conserva path y reload en la shell.

### Paletas de fuentes

`config palette list` muestra las opciones. `config palette sunset`, `config palette golden` y `config palette gruvbox` seleccionan la paleta persistente en `SST_FONT_PALETTE`. El fondo y el logotipo no cambian. Los colores de estado conservan su distinción semántica.

Para listar las paletas: config palette list
Para consultar la activa: config palette
Autocompletado: config palette <TAB>

Las paletas también se aplican a los elementos gráficos de `demo graficos`. Cambia el esquema con `config palette sunset`, `config palette golden` o `config palette gruvbox` antes de entrar al catálogo. No es necesario reiniciar SST.

Oxidize y ronin-sunset: colores muestreados de las imágenes JPEG, no códigos publicados. Las otras referencias conservan los HEX impresos o los RGB del archivo GPL. Los tonos oscuros pueden aclararse para lectura y se conservan los colores semánticos SST cuando falta un tono de estado adecuado. No cambia el fondo ni el logotipo.

Dentro de `demo graficos`, pulsa P para la paleta siguiente y O para la anterior. El nombre del esquema aparece en la cabecera. Las 18 paletas se recorren circularmente; el cambio conserva la familia, foco y animación. Al salir se conserva la configuración original de `config palette`. Para fijar un esquema de forma permanente, usa `config palette NOMBRE` fuera de la demo.

La identidad gráfica se aplica ahora también a la terminal habitual: los trazados compartidos del catálogo se usan en marcos y transferencias; las cabeceras, tablas, selección, cursor e indicadores de métricas utilizan los roles de la paleta activa. La salida de máquina y los datos de los comandos se conservan. Las muestras que no tienen una función aplicable al contexto siguen disponibles en `demo graficos`.
