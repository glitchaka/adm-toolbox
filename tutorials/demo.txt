SST — Catálogo nativo de elementos gráficos

Uso: demo graficos

Controles: ←/→ familia, 1–6 acceso directo, PgUp/PgDn ±3, Inicio/Fin extremos, Tab/↑/↓ foco, Mayús+Tab anterior, Enter prueba interacción, Espacio pausa/reanuda, R reinicia, Esc/q sale.
Los datos y acciones son simulados. No se modifica el equipo, el formatter, el logo ni las paletas de la consola habitual. No se cargan ilustraciones o archivos de imagen.

El catálogo hereda el esquema activo de config palette (gruvbox, sunset o golden). Los colores de los componentes se derivan de los roles de texto del formatter; los fondos del usuario y el logotipo no cambian. El agrupador de campos sustituye al pórtico decorativo.

El catálogo sigue el selector de los 18 esquemas. Consulta config palette list o guide config.

Dentro de `demo graficos`, pulsa P para la paleta siguiente y O para la anterior. El nombre del esquema aparece en la cabecera. Las 18 paletas se recorren circularmente; el cambio conserva la familia, foco y animación. Al salir se conserva la configuración original de `config palette`. Para fijar un esquema de forma permanente, usa `config palette NOMBRE` fuera de la demo.


La presentación de informes, métricas, tablas y estados utiliza la paleta activa. Tab muestra las sugerencias; flechas o Tab recorren las alternativas, Enter acepta y Esc cancela. F2 expande o contrae las sugerencias. Aceptar una sugerencia no ejecuta el comando.
