SST — Guide / manual interactivo

Objetivo

`guide` es un visor interactivo de la documentación publicada en el repositorio. El ejecutable SST no contiene el catálogo de áreas, comandos, aliases ni descripciones.

Fuente de verdad

  tutorials/guide-index.json

Ese archivo define:

  orden y nombre de las áreas
  descripciones de las áreas
  comandos visibles
  aliases
  resúmenes
  relación comando -> manual
  tipo de extracción del manual
  textos principales de la interfaz de Guide

Los documentos abiertos por cada entrada viven también bajo `tutorials/`.

Esto permite agregar, quitar, mover o renombrar contenido de Guide sin recompilar SST. Una nueva entrada documental se publica modificando el repositorio; el binario conserva únicamente el motor TUI que descarga, valida, indexa y renderiza el catálogo.

Disponibilidad

`guide` carga `guide-index.json` al invocarse. No existe un catálogo local de respaldo.

Si el repositorio no responde, el índice no existe o el JSON es inválido, Guide no inventa ni muestra contenido embebido: el comando devuelve únicamente una línea vacía.

Los manuales individuales se descargan cuando se abren y se mantienen en memoria durante la sesión para evitar descargas y parseos repetidos.

Formas públicas

  guide
  guide COMANDO
  guide search TEXTO
  guide -h
  guide --help

Office no es un área independiente. Sus acciones pertenecen a Herramientas mediante la familia `tools office ...`.

Dentro de cada área se muestran las entradas definidas por `guide-index.json`. Al seleccionar una, Guide abre el documento indicado por el propio índice.

Controles — áreas y comandos

  Up/Down                  navegar
  PgUp/PgDn                salto
  Home/End                 inicio/final
  Enter                     abrir área o manual del comando
  Backspace                volver al nivel anterior
  /                         buscar en toda la guía
  q / Q / x / X            salir
  Esc                       volver o salir según el nivel

Controles — manual de un comando

  Up/Down                  desplazamiento línea a línea
  PgUp/PgDn                desplazamiento por páginas
  Home/End                 inicio/final
  Backspace / Enter / Esc  volver al área
  q / Q / x / X            salir de Guide

Búsqueda

  guide search TEXTO

También puede iniciarse con `/` dentro de Guide. El índice de búsqueda se construye una sola vez al abrir Guide usando nombre, aliases, área y descripción publicados por el repositorio.

Rendimiento

Guide es dirigido por eventos. No redibuja toda la pantalla periódicamente cuando el usuario no hace nada.

Se vuelve a renderizar únicamente al cambiar:

  selección
  búsqueda
  scroll
  vista
  tamaño de terminal

Los manuales descargados y su versión ya envuelta al ancho actual se mantienen en caché de memoria para evitar volver a descargar, extraer y envolver el mismo texto en cada frame.

Regla editorial

Cada comando debe incluir en su propia ficha, cuando aplique:

  descripción y caso de uso
  sintaxis completa
  todos los subcomandos
  todos los flags cortos y largos
  todos los aliases públicos
  parámetros y valores admitidos
  valores por defecto
  combinaciones válidas
  ejemplos reales
  permisos y UAC
  backend utilizado
  efectos y cambios realizados
  salida esperada
  errores habituales
  validación posterior
  recuperación o reversión

No se permiten `etc.`, `[OPCIONES]` genéricos ni familias resumidas cuando el parser de SST implementa opciones concretas. Helpers internos no se presentan como funciones normales.
