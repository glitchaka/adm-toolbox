SST — Gestor de paquetes nativos: instp

SST-PACKAGE/1 es el estándar de integración y .pkgx es la extensión
del contenedor TAR + GZIP. Solo se instalan módulos adaptados a SST.
No se descargan herramientas externas como ejecutables independientes.

Consultar:
  instp
  instp help
  instp search [TEXTO]
  instp info PAQUETE
  instp list
  instp PAQUETE

Instalar desde catálogo o archivo local:
  instp install powershell
  instp install powershell -p
  instp install RUTA\\MODULO.pkgx --persistent

Quitar y actualizar:
  instp remove PAQUETE
  instp upgrade [PAQUETE]      actualiza módulos ya instalados
  instp update                refresca solo índices de repositorios
  instp check sst             consulta la versión de SST
  instp upgrade sst           prepara actualización del núcleo y la aplica al cerrar
  instp sst                   versión y canal de actualización

Gestionar repositorios de paquetes SST:
  instp repo list
  instp repo add NOMBRE URL [PRIORIDAD]
  instp repo remove NOMBRE
  instp repo update
  instp cache clean
  instp doctor

Interfaz de catálogo:
  sigsour                     consulta e instala módulos mediante instp

Seguridad:
  - paquetes .pkgx con manifiesto, hashes SHA-256 y rutas verificadas
  - despliegue transaccional en packages/win/modules o árbol nativo apropiado
  - solo módulos registrados se cargan en la consola
  - no añadir .exe externos ni ejecutar instaladores de otros sistemas
  - paquetes temporales caducan con la generación funcional; -p persiste

Arch Linux:
  Su listado de paquetes es una referencia para adaptar capacidades a SST.
  No es un entorno instalable desde instp y no se utiliza WSL2.
  Cada adaptación requiere código propio y su propio .pkgx.

No confundir instp update (índices) con instp upgrade sst (núcleo).
