# Shell Shock Tool 0.1.0

Primera publicación consolidada de Shell Shock Tool.

Incluye la terminal Win32 propia, identidad visual y Nerd Font portable, helix-sst basado en Helix 25.07.1, utilidades Unix integradas, herramientas administrativas y de red, y el intérprete Bash nativo ampliado con control de flujo, arrays, expansiones, heredocs, redirecciones, opciones de shell, lectura interactiva y ejecución de scripts .sh.

Esta publicación corresponde al código fuente consolidado en `main`. La compilación y las pruebas permanecen como acciones manuales y no se ejecutan durante la publicación.
