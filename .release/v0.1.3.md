# Shell Shock Tool 0.1.3

Corte de desarrollo centrado en la capa Bash nativa.

## Cambios principales

- Amplía sustancialmente la compatibilidad con Bash 5.3.
- Completa y corrige control de jobs, background, pipelines y coprocesos.
- Añade process substitution y redirecciones avanzadas, incluidos descriptores asignados a variables.
- Amplía arrays, namerefs, atributos de variables, scopes locales y variables especiales de Bash.
- Completa globbing avanzado, extglob, globstar, GLOBIGNORE, GLOBSORT y opciones relacionadas.
- Amplía history, readline/bind, programmable completion y opciones de shell/shopt.
- Completa builtins como hash, jobs, wait, fg, bg, disown, exec, history, fc, bind, enable, complete, compgen, compopt, suspend, mapfile/readarray, ulimit, times y caller.
- Añade cambios específicos de Bash 5.3, incluidas sustituciones de comando en el shell actual y compgen -V.
- Corrige la expansión de aliases para realizarse antes del parser y admitir operadores introducidos por aliases.
- Amplía la expansión de ~usuario y corrige globskipdots.
- Repara el quoting localizado $"..." que había quedado truncado en una revisión intermedia.

## Estado de este release

Este release se publica sin ejecutar compilación ni suite de pruebas durante la preparación del corte, siguiendo el flujo de desarrollo del proyecto. La validación se realizará posteriormente de forma explícita.
